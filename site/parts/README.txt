# Demo / case photos for replacement-parts.html

The "Capability demo" section (#work) in replacement-parts.html is WIRED to the
three carabiner files below but is kept `hidden` until they exist here — a
broken-image icon on a live page reads worse than no section at all.

To publish the demo:
  1. Save these three files into this folder, with EXACTLY these names:
       Carabiner-Scan.jpg                 - CamScan measurement overlay
       Carabiner-Replica-CAD.jpg          - the Fusion model
       Carabiner_3D_Print_Comparison.jpg  - printed part beside the original
     Export ~1200 px wide, JPEG quality ~80 (the page is built for mobile data).
  2. Delete the `hidden` attribute on <section id="work"> in
     replacement-parts.html.

Naming for further cases: case2-broken.jpg, case2-measured.jpg, case2-printed.jpg
Referenced from the page as /parts/<name>.jpg
